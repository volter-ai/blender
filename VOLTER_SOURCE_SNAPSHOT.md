# Volter Blender source snapshot

This repository is the corresponding source for Volter Editor's Blender
WebAssembly engine. It intentionally contains no history from Volter's private
development repository.

The initial source tree was materialized from the reviewed source archive for
revision `a4dff7ba16a0cca24504d81ed0086457493e48dc`, based on official Blender
`fbe6228777e7d9afefcd61a413844e790ae75db7` (Blender 5.2.0 LTS). The archive's
SHA-256 is `60f4789ec1a3bc9379bc208c7ce28ee1a4fee7787436a998b2d1ed5748689ec4`.
`SOURCE_PROVENANCE.json` records those inputs in machine-readable form.

Build instructions for the WebAssembly distribution are in
`build_files/emscripten/RELEASE.md`. The licenses and notices already in this
tree continue to govern their respective files.
